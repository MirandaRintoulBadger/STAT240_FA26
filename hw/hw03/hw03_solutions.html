Starting from planets, print out the planet name, mass, radius, and density of the top five most dense planets.

The density of a planet is its mass divided by its volume.

The volume of a planet is \(\frac{4}{3} \times \pi \times \text{radius}^3\). Note that pi is a constant bult into R that you may use.

planets %>%

Problem 6

Consider comparing the rate of obesity with the rate of bachelor’s degree attainment in different Wisconsin counties. We’ll use datasets education_long.csv, which is already cleaned, and obesity.csv, which you’ll need to tidy.

Right now, the obesity data has one row for every zip-sex-age group combination; age groups are 5 years old - 17 years old, 18-34, 35-54, 55-74, and 75+.

We want to obtain a version of the obesity dataset we can merge with education above; so both datasets would have to have one row for every zip-sex combination.

This means we need to summarize() the obesity dataset to obtain one row per zip-sex combination, purposefully “smoothing over” all the age group detail we currently have.

Create a new dataset called obesity_summary by executing the following steps:

  • Start from obesity.

  • Remove all rows with data about the youngest age group (05-17), since the education dataset is only about adults.

  • Within each row, calculate the estimated obesity rate, est_obese_rate, by taking obese/n. (n is the number of people we have data for; pop is the total population, so obese/n is just an estimate)

  • Within each row, calculate est_obese_pop by taking est_obese_rate * pop. We are estimating the true obese population by multiplying a sample obesity rate times the full population.

  • Group and summarize the data, such that you obtain one row per zip-sex combination (like in education), with the information:

    • Total population within that zip-sex combination: call this total_pop

    • Total obese population (estimated) within that zip-sex combination: call this est_total_obese_pop.

    • Note that you will have to use na.rm = T when summarizing to avoid NAs.

  • Remove all rows where there are 0 estimated obese individuals. (Optional question: Why didn’t we just do this at the beginning?)

Let the first few rows be printed as output in your knitted file. If done correctly, your first few rows should look like this:

     zip sex    total_pop      est_total_obese_pop
   <dbl> <chr>      <dbl>                    <dbl>
 1 53001 female       726                   259.02
 2 53001 male         755                   330.63
 3 53002 female       977                   369.63
 4 53002 male        1052                   404.50
obesity_summary <- obesity %>% 
  filter(age != "05-17") %>%       # Remove non-adults
  mutate(
    est_obese_rate = obese/n,      # Observed/estimated obesity rate
    est_obese_pop = est_obese_rate * pop     # Estimated obese pop
  ) %>%
  group_by(zip, sex) %>% 
  summarize(
    total_pop = sum(pop, na.rm = T),
    est_total_obese_pop = sum(est_obese_pop, na.rm = T)
  ) %>% 
  filter(est_total_obese_pop != 0)
