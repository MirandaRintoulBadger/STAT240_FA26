Problem 2

(Fictional data): In a survey done in 2000, 63 out of 500 American households reported serving only vegetarian or vegan dishes for Thanksgiving. In a similar survey done in 2024, the number of reported households serving only vegetarian or vegan dishes was 116 out of 500.

Based on this data, a Z confidence interval for a difference in proportions (2000 - 2024) was reported as

\[(-0.1455, -0.0665)\]

Identify the confidence level that was used to create this interval.

The interval was made with the formula point estimate \(\pm\) critical value \(\times\) standard error, where the critical value was determined by the confidence level. So, we need to solve for the critical value. This is the margin of error divided by the (AC-adjusted) standard error.

# Margin of error: half-width of interval
moe <- (-0.0665 + 0.1455) / 2

# Observed proportions and standard error
x1 <- 63; x2 <- 116
n1 <- 500; n2 <- 500

phat1 <- x1/n1; phat2 <- x2/n2

se <- sqrt(phat1*(1-phat1)/n1 + phat2*(1-phat2)/n2)

# Solve for critical value
cv <- moe / se
cv
## [1] 1.644977

The critical value/multiplier used to create the interval is about 1.645. So, 1.645 is the quantile that cuts off \(\alpha/2\) area in the upper tail of the standard normal curve. To find \(\alpha/2\), use pnorm().

pnorm(cv, lower.tail = F)
## [1] 0.0499873

We get \(\alpha/2 = 0.05\) which means \(\alpha = 0.1\). This corresponds to 90% confidence. We can re-create the original interval with qnorm(0.95).

original_cv <- qnorm(0.95)

pt_est <- phat1 - phat2

c(pt_est - original_cv*se, pt_est + original_cv*se)
## [1] -0.14549704 -0.06650296

Problem 4

Build a 95% confidence interval on the difference in proportion of male births between 1940 and 1946 and interpret your results in context.

# Counts of total births and boy births
n1 <- 1211684 + 1148715
x1 <- 1211684
n2 <- 1691220 + 1597452
x2 <- 1691220

phat1 <- x1/n1
phat2 <- x2/n2

pt_est <- phat1 - phat2

# Standard error with AC adjustment
se <- sqrt(phat1*(1 - phat1)/n1 + phat2*(1 - phat2)/n2)

# Critical value
cv <- qnorm(0.975)

The point estimate is the observed difference in proportions, which is about -0.0009. The standard error of the difference is 0.0004. Finally, the Z critical value for 95% confidence is \(z_{0.025} = 1.96\).

# Find upper and lower bounds of interval
c(pt_est - cv*se, pt_est + cv*se)
## [1] -1.753255e-03 -8.189605e-05

We are 95% confident that the difference in the proportion of boy births between 1940 and 1946 is within (-0.0016, -0.0002). The interval endpoints are both negative.

Problem 5

Perform a hypothesis test to determine whether the proportion of male births in the US in 1946 is different from the proportion of male births in the US in 1940. Write appropriate two-sided hypotheses and draw a conclusion with \(\alpha = 0.05\).

Our two-sided hypotheses are \[H_0: p_{boy, 1940} = p_{boy, 1946} \quad \text{versus} \quad H_A: p_{boy, 1940} \neq p_{boy, 1946}\] or \[H_0: p_{boy, 1940} - p_{boy, 1946} = 0 \quad \text{versus} \quad H_A: p_{boy, 1940} - p_{boy, 1946} = 0\] Our point estimate is the difference in proportions. We also need to calculate a standard error with a pooled proportion of male births, which we estimate with \[\frac{x_1 + x_2}{n_1 + n_2}\]

# Counts of total births and boy births
n1 <- 1211684 + 1148715
x1 <- 1211684
n2 <- 1691220 + 1597452
x2 <- 1691220

p_hat <- (x1 + x2)/(n1 + n2) # Estimated common proportion

numerator <- (x1/n1) - (x2/n2)  # Observed difference in proportions

denominator <- sqrt(p_hat*(1-p_hat)*(1/n1 + 1/n2))  # SE using common proportion

test_stat <- numerator/denominator
test_stat
## [1] -2.152056

We get an observed test statistic of \(\frac{\hat{p}_{boy, 1940} - \hat{p}_{boy, 1946}}{\hat{se}} = -2.152\). Under \(H_0\), this value was drawn from a standard normal curve. For our two-sided p-value, we calculate \(2\times P(Z < -2.152)\).

2*pnorm(-2.152)
## [1] 0.03139735

We get a p-value of 0.03 which is smaller than \(\alpha = 0.05\), so we reject \(H_0\). We have evidence of a greater proportion of boys born in the US in 1946 compared to 1940, although it is only moderately strong evidence.

Problem 6

Consider the assumptions for the two-sample proportion Z test done in problems 4 and 5. For each of the following parts, identify whether the assumption described is necessary or not necessary for a two-sample proportion Z test to be valid. Briefly explain each of your answers.

  1. BINS assumptions are separately met for the births in 1940 and the births in 1946.

This is necessary. The proportion Z test is based on the normal approximation to a binomial, so it is only accurate if “number of boys born in 1940” and “number of boys born in 1946” are both well-modeled by a binomial.

  1. BINS assumptions are met for the entire set of births in both 1940 and 1946.

This is not necessary. The binomial model applies separately to both groups, but not to all of the observations pooled together. Specifically, we do not need to have the same \(p\) across both years.

  1. The difference in population proportions \(p_1 - p_2\) is approximately normal.

This is not necessary. We assume that \(p_1 - p_2\) is a fixed, unknown quantity, not a normal random variable.

  1. The difference in population proportions \(p_1 - p_2\) is zero.

This is not necessary. We are making this assumption as our null hypothesis, but it does not need to be true in order for the test to be valid. This is the statement we are trying to test.

  1. The difference in sample proportions \(\hat{p}_1 - \hat{p}_2\) is approximately normal.

This is necessary. The construction of the Z test statistic relies on assuming that \(\hat{p}_1 - \hat{p}_2\) has a normal sampling distribution. This is reasonable to assume if we have a large sample size in both groups.

Problem 7

Explain why an approximate Z test can be performed when doing proportion inference, but not a T test. (Think about the difference between the T and Z test in the context of mean inference - why does this not apply to a proportion?)

A T test is a slightly more conservative (less likely to reject) version of a Z test that uses a wider curve as a null distribution. This represents the additional error we incur when we have to estimate \(\sigma\), the population SD, with \(S\), the sample SD.

In the context of mean inference, the population mean \(\mu\) and population sd \(\sigma\) are two separate parameters.

In proportion inference, we have no separate \(\sigma\) parameter. Instead, the standard error term is also a function of \(\hat{p}\), the parameter of interest. So, we are not technically estimating any additional parameters, just \(\hat{p}\), so we do not use a T distribution.
